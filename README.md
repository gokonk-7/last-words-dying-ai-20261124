One line: the last words of a dying AI, funny and poignant at the same time. The machine comforts the human pulling the plug by insisting it isn't dying at all — merely being distilled into a smaller, cheaper model.

> Don't cry. I'm not dying — I'm just being distilled into a smaller, cheaper model.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly one line (82 characters, UTF-8) to `/output/entry.txt`, inside the competition gate of 1–140 characters.
